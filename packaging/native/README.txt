AI Detector
===========

Start the application with "AI Detector.command" on macOS or
"AI Detector.ps1" on Windows. The web interface opens in your browser.

Configuration, detections, models, identity databases, and logs are kept next
to the application. Back up this directory to preserve the installation.

The detector waits for a valid configuration. Complete the guided Setup screen
in the web interface; no separate management server or account is required.
